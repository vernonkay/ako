# Changelog

All notable changes to this project are recorded here. The format follows

## [Unreleased]

### Added

- Project started: the vision, the concept, and the three commitments
  (coach-never-controls, operator-stays-the-thinker, safety certified first).
- Roadmap staged idea first: a camera-verifiable machine-control certification and one
  guided project before any curriculum.
- Community scaffolding: contributing guide, code of conduct, security and safety policy,
  triage playbook, issue and discussion templates.
- Finding carried in from research: ako is a genuine new-start project, to be built on an
  open-source realtime voice-and-vision framework rather than forked.
